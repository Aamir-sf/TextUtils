## 🔥 Features
- 🔠 Convert text to **Uppercase & Lowercase**
- 🧹 **Clear** text instantly
- 🔊 Listen to text with **Text-to-Speech**
- 📋 **Copy** text to clipboard
- 📊 **Word & Character count**
- ⏳ Estimate **Reading time**
- 👀 Live **Text Preview**
- 🌗 **Dark Mode**
